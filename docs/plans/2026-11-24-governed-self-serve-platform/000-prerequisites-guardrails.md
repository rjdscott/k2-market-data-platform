# Phase P0: prerequisites and guardrails

**Depends on:** nothing
**Decision it implements:** none. It repairs what the later phases stand on. Umbrella: [ADR-031](../../adr/ADR-031-governed-self-serve-platform.md).
**Delivers:** a README that says what the platform is and whose data it handles, a repository with no real venue market data in it, a running stack with one command for the six existing gates, a CI gate on the resource sum, a lock exit code that cannot be confused with an error, a patched catalog, and the stale facts found while planning corrected.
**Exit:** `make gates` passes on the live stack; the CI `compose` job prints three sums and fails above the ceiling; an ingest that finds the lock held exits 75 and a test asserts it; `/release-check` smoke queries match the stack that exists today.

## Scope

**Pull request 1: gates and stale facts**

- `make gates`: `test`, `lake-verify`, `parity-ohlcv`, `parity-bars`, `check-alerts`,
  `check-docs`, in that order. Every later phase runs it before every merge.
- CI `compose` job (`.github/workflows/ci.yml:141-156`): print three sums in GiB, steady
  default, bootstrap default (one-shots included), bootstrap with `--profile governance`.
  In this phase the gate fails when the steady default exceeds 16 CPU / 40 GB and only
  reports the bootstrap figure, which is 16.10 CPU today. ADR-034 in P2 moves the gate to
  the bootstrap default at 20 CPU / 36 GiB. The limits-present check also runs with
  `--profile governance`, so a profiled service cannot ship without limits. A further check
  fails an image with no tag or a dependency with no pinned version.
- `scripts/check-docs.sh`: a gate rejecting U+2014 on lines added relative to `origin/main`
  in Markdown, Python, shell, SQL and YAML. The `docs` job checks out with full history so
  the comparison exists. Gate count updated in `README.md`, `docs/development/testing.md`
  and `Makefile`.
- `Makefile:74-78`: `prom/prometheus` gets the tag the compose file uses.
- Stale facts: the `spark-iceberg` row in the compose summary comment; the ADR count at
  `README.md:86`; the GiB figures at `docs/adr/README.md:5`; one required engine memory value
  in both `docs/development/setup.md` and `docs/runbooks/fresh-install.md`; the six drift
  rows listed in the plan README.
- `.claude/skills/release-check/SKILL.md`: lake and `gold` smoke queries in place of the
  dropped `k2.silver_trades`; the test description corrected.

**Pull request 2: what the repository is, and the data in it**

- `README.md`, near the top, "What this is, and data terms": a platform run locally for
  research and quant workflows; a reference implementation, not a hosted service; not a
  market data distribution service and not for production trading; not affiliated with any
  venue or the ECB. The repository ships code and contracts. Market data is fetched by the
  user's own stack from public endpoints, stays there, and is subject to each provider's
  terms, which are linked and are the user's responsibility.
- `NOTICE`: every third-party data file in the tree, its source and its terms; and the
  statement that the MIT licence covers the code.
- Synthetic fixtures. The real websocket frames under
  `services/capture-rust/tests/fixtures/` and the sample files beside the research spikes
  are replaced by synthetic frames in each venue's exact format, generated by a committed
  script with a fixed seed. The golden hashes that
  [ADR-029](../../adr/ADR-029-research-production-parity-contract.md) pins are re-pinned in
  the same pull request, and an Outcome appended there says why. The research notes keep
  their text and gain one "Resolved" line.
- `make record-fixtures`: captures real frames on the user's own machine into an ignored
  directory, and runs the replay tests against them. Stronger evidence, never committed.
- A CI check: a data file under a fixtures or samples directory must be named `synthetic-*`
  or be listed in `NOTICE`.
- A sweep of existing documents for venue price or volume values. Any found is removed in a
  new dated snapshot with a "Resolved" line on the old one, per the immutability rule.
  Figures about the platform's own behaviour stay.
- Old commits still contain the old files. That is stated in the ADR-029 Outcome. History is
  not rewritten.

**Pull request 3: lock exit code**

- `docker/lake/ingest.py`: lock held exits 75 (`EX_TEMPFAIL`) in place of 2. The Prefect flow
  raises on any non-zero exit (`lake_flows.py:72-79`), so its behaviour does not change.
- Chaos scripts and `docker/lake/README.md` that mention exit 2 updated. A unit test holds
  the lock and asserts 75.
