# Generated Iceberg DDL

Generated by `k2gen generate` from contracts/. Do not edit: change the contract, then `make generate`.

`k2gen generate` deletes this directory and writes it again on every run. It holds one
`<namespace>.<table>.sql` per contract, from its inline columns
([ADR-032](../../../../docs/adr/ADR-032-odcs-contracts-and-k2gen.md)). Nothing applies them today: `apply_ddl.py`, which did,
retired with the old lake ingest to `legacy/v3-lake-ingest/`
([ADR-056](../../../../docs/adr/ADR-056-unified-data-product-platform.md)).

None today: no product has a contract.
